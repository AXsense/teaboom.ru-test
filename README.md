## Запуск

Откройте `index.html` в браузере.

## Реализовано

- адаптивная верстка для desktop / tablet / mobile;
- выбор фасовки с обновлением артикула и выбранного состояния;
- демонстрационное добавление в корзину и счетчик;
- кнопка избранного и увеличение изображения;
- вкладки «Описание», «Свойства», «Отзывы»;
- мобильное меню и кнопка прокрутки наверх;
- выпадающее меню вкладки "Каталог".
